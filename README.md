# React app with a simple API

This starter uses React and Vite for the frontend and Express for the backend.
The frontend calls the backend's single endpoint, `GET /api/hello`.

## Run locally

1. Install dependencies with `npm install`.
2. Start both the frontend and API with `npm run dev`.
3. Open the local URL printed by Vite (usually `http://localhost:5173`).

The API listens on port `3001`. During development, Vite proxies `/api` requests
to the API server. To run the API by itself, use `npm start`.
